Spring

A physics-based 3D spring simulation closure based module using numerical integration. Useful for smooth object physics and camera movement.

Types​

State​

</>
interface State {
Position: Vector3--

The current position of the spring.

Target: Vector3--

The target position the spring is moving towards.

Velocity: Vector3--

The current velocity of the spring.

Mass: number--

The mass of the spring.

Force: number--

The force applied to the spring.

Damping: number--

The damping factor (friction) of the spring.

Speed: number--

The simulation speed multiplier.

Iterations: number--

The number of calculation iterations per update for stability.

}

Represents the current physical state and properties of the spring.

SpringObject​

</>
interface SpringObject {
Update: (deltaTime: number) → Vector3--

Steps the simulation forward and returns the new position.

ApplyImpulse: (force: Vector3) → ()--

Applies an instantaneous force to the spring's velocity.

SetState: (state: PartialState) → ()--

Updates specific properties of the spring's state.

GetState: () → State--

Returns a read-only copy of the current state.

}

The Spring object instance containing the methods to simulate and interact with the spring.
